# 🌐 Enable GitHub Pages (3 Steps)

## Step 1: Go to Repository Settings

Visit: **[https://github.com/andreolf/vitalik-hunt-web/settings/pages](https://github.com/andreolf/vitalik-hunt-web/settings/pages)**

## Step 2: Configure GitHub Pages

Under **Build and deployment**:

1. **Source:** Select `Deploy from a branch`
2. **Branch:** Select `main`
3. **Folder:** Select `/ (root)`

## Step 3: Click Save

GitHub will automatically build and deploy your site within 1-2 minutes.

---

## ✅ Your Site is Live!

Once deployment completes, access it at:

### 🌐 [https://andreolf.github.io/vitalik-hunt-web](https://andreolf.github.io/vitalik-hunt-web)

---

## Troubleshooting

**Still seeing 404?**
- Wait 2-3 minutes for the build to complete
- Check the **Deployments** tab for build status
- Refresh your browser (Ctrl+Shift+R to clear cache)

**Build failed?**
- Click the failed deployment in the **Deployments** tab
- Check the error logs
- Ensure all dependencies are installed: `pnpm install`
